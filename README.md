# BVN Online · 下载与使用说明

把自己的 Windows 电脑作为服务器，朋友通过浏览器打开邀请链接游玩。支持 **BVN 3.3 和 3.8.8.5**。

**本仓库公开提供发行包、使用说明和问题反馈。开发源码现已转为私有维护，不在本仓库公开。**

Windows 10 / 11 64 位，完整解压后运行 **BVN Online.exe**；无需另外安装 Node.js。GitHub 自动生成的 “Source code” 压缩包仅包含本下载仓库的说明文件，不是游戏程序。

## 开始游玩

1. 选择 3.3 或 3.8.8.5，点击「开始开服」。互联网模式会生成临时 HTTPS 邀请网址。
2. 点击「浏览器游玩」。3.3 自动准备游戏；3.8.8.5 玩家选择自己电脑上的官方游戏根文件夹并完成校验。
3. 创建房间，点击「邀请朋友」复制房间链接。朋友打开链接，举手后由房主安排上场，也可以直接观战。
4. 不玩时点击「关闭电脑服」，或退出程序窗口。仅关闭浏览器不会关服。

支持个人／小队、血量和时间设置、最多 8 人房间、实时成员、观战、举手替补和侧栏表情。1.0.0 桌面版不提供人机模式。

开服电脑需要持续运行、联网。自动邀请地址属于临时连接，重开可能变化；延迟和连通性取决于双方网络，也可选择局域网或自备公网映射。3.8.8.5 内存占用较大，建议每台电脑只开一个对战页面。
